藥你管 🐾

讓寵物健康管理更簡單,讓每一份照護都有跡可循。

「藥你管」是一個以寵物健康與用藥管理為核心的系統構想,希望透過數位化的方式,協助飼主整理寵物的健康資訊、用藥紀錄及日常照護資料,減少照顧過程中可能發生的遺漏與混亂。

我們希望讓飼主能夠更方便地掌握寵物的健康狀況,也讓獸醫在看診時能取得更完整的相關資訊。

2飼主在照顧寵物時可能遇到的困難

以下為我們的初步推測,將透過獸醫訪談驗證。

💊

1. 用藥管理不易

  • 需按獸醫指示定時餵藥,忙碌時容易忘記。
  • 不同藥物的使用時間與頻率不同,容易記錯或搞混。
  • 多隻寵物或多種藥物同時管理,負擔增加。
  • 不清楚過去用過哪些藥,難以快速回顧。
📈

2. 健康紀錄不完整

  • 沒有固定記錄體重、食慾、活動力及排便狀況。
  • 寵物異常時,難以回想症狀從何時開始。
  • 過去的檢查結果與資訊分散各處。
🏥

3. 就醫資訊容易遺漏

  • 看診時忘記告知病史或曾用藥物。
  • 不一定記得上次看診日期、檢查結果與醫囑。
  • 各次看診資料缺乏整理,難以看出長期變化。
📚

4. 寵物照護知識不足

  • 不同種類寵物習性與需求不同,飼主未必清楚。
  • 網路資訊眾多,難以判斷正確性。
  • 出現異常時,不知如何處理或何時該就醫。
🐾

5. 多隻寵物管理不方便

  • 需分別管理每隻寵物的健康與用藥資料。
  • 容易混淆不同寵物的藥物或看診紀錄。
  • 家人共同照顧時資訊不同步,可能重複餵藥或遺漏。

3初步系統功能構想

針對上述問題規劃的五大功能。

🪪

1. 寵物基本資料管理

  • 建立寵物個人檔案。
  • 記錄名稱、種類、生日、體重等資訊。
  • 支援多隻寵物個別管理。
⏰

2. 用藥管理與提醒

  • 記錄獸醫開立的藥物名稱及使用方式。
  • 設定用藥提醒,協助按時餵藥。
  • 保存過去用藥紀錄,方便查詢。
🩺

3. 寵物健康紀錄

  • 記錄體重、食慾、活動力及日常狀況。
  • 保存健康變化。
  • 整理長期健康資訊。
📋

4. 就診與檢查紀錄

  • 記錄看診日期、原因及獸醫注意事項。
  • 保存檢查結果及相關資料。
  • 方便回顧過去就醫紀錄。
📖

5. 寵物照護資訊

  • 提供各種類寵物的基本照護資訊。
  • 整理日常照顧與健康管理知識。
  • 協助尋找可靠的照護資訊。

★特殊寵物的需求假設

我們希望專題與一般貓狗系統有所區隔,聚焦在「特殊寵物」。

⚠️ 以下內容為團隊依資料整理的「假設」,尚未經專業驗證,將於獸醫訪談中確認與修正。本站不提供任何醫療建議。

兔子、天竺鼠、倉鼠、龍貓等

  • 體型小,藥量以極小的 ml 計算,飼主可能難以精準給藥。
  • 食慾與排便量是重要警訊,記錄需求高。
  • 部分藥物對小型草食動物有特殊風險,飼主需明確遵守醫囑。待訪談確認
  • 餵藥可能造成壓力,需要餵藥方式與技巧的說明。

鸚鵡、文鳥等鳥類

  • 鳥類常不易顯露病徵,每日體重(公克)與進食量的追蹤可能很重要。待訪談確認
  • 餵藥需保定,飼主可能缺乏安全操作的知識。
  • 飲食、環境與健康關聯高,需要記錄飼料與環境資訊。

鬃獅蜥、守宮、陸龜、蛇等

  • 疾病常與飼養環境(溫度、濕度、紫外線燈)有關,環境紀錄可能比用藥紀錄更重要。待訪談確認
  • 進食頻率、蛻皮、排泄狀況需要長期追蹤。
  • 專門的爬蟲獸醫較少,看診前整理資料可提高效率。

雪貂、刺蝟、蜜袋鼯等

  • 不同物種的照護知識差異大,飼主的資訊來源分散。
  • 疫苗、用藥與常見疾病資訊較難查詢。待訪談確認
  • 適合作為「照護資訊」功能的重點整理對象。

跨物種的共同假設

  • 特殊寵物獸醫數量少,每次看診的資料完整度更加重要。
  • 不同物種的「重要紀錄項目」不同(體重、環境、飲食…),系統可能需要依物種客製欄位。
  • 特殊寵物的用藥可能需要獸醫特別調配,飼主需要保存劑量與保存方式(如冷藏)。
  • 飼主的照護知識多來自社群與網路,正確性參差不齊。

4預計使用對象

本系統初步以一般寵物飼主為主要使用對象。目前尚未限定特定寵物種類,初步希望了解犬、貓及其他特殊寵物飼主在健康管理與用藥方面的不同需求。

後續將透過獸醫訪談及資料蒐集,評估適合優先支援的寵物種類。

5專題研究目的

我們希望透過本專題,了解飼主在寵物健康管理及用藥過程中可能遇到的問題,並嘗試利用資訊系統改善資料整理與日常管理上的不便。

目前列出的困難與功能皆為初步構想,尚未確認是否符合實際需求,因此希望透過獸醫訪談,了解目前寵物醫療與照護上的常見問題,作為後續系統設計及功能規劃的參考。

★預計向獸醫請教的問題

訪談時希望釐清的方向。

  1. 飼主面:飼主帶寵物來看診時,最常遺漏或說不清楚的資訊是什麼?
  2. 用藥面:飼主在餵藥或給藥時,最常見的錯誤或困難有哪些?(漏餵、劑量、保存方式…)
  3. 用藥面:不同物種的用藥,有哪些是飼主一定要知道的注意事項?
  4. 紀錄面:如果飼主能事先整理資料,您最希望看到哪些項目?(體重、食量、排便、環境…)
  5. 特殊寵物:您認為哪一類特殊寵物的飼主最缺乏資源或資訊?
  6. 特殊寵物:特殊寵物的飼養環境紀錄,對診斷的重要程度為何?
  7. 溝通面:醫囑通常如何傳達給飼主?(口頭、紙本、藥袋標示)飼主回家後常忘記什麼?
  8. 風險面:您認為飼主使用 App 紀錄或提醒時,有哪些該避免的設計或風險?(例如誤導用藥)
  9. 資訊面:目前網路上的寵物照護資訊,常見的錯誤觀念有哪些?
  10. 整體:如果有一個這樣的系統,您會希望它具備哪些功能?哪些功能其實沒有必要?
